## What's new

- **The same three things to do.** A parent sees the same three suggestions as their student, in the same order. A
  parent's own tasks, like checking the cost, show up among them instead of in a separate list.
- **The same guides.** The test, recommenders, courses, visits, college list, and story pages read the same for a
  parent as for the student. A parent with edit access can now update next year's courses and mark a college as
  followed.
- **Still the student's.** The story's text stays private to the student, and picking an Early Decision round is
  still the student's call.

## Behind the scenes

- The plan page, the move cards, and the guides no longer branch on whether the viewer is a parent, except where the
  server keeps something the student's (the story, the ED round). Parent emails are unchanged.
