## What's new

A college's profile used to open with **What changed**, the list of figures revised in recent data releases, before
the at-a-glance cards. The page now starts with the college itself. What changed sits at the end, after "Schools like
this one", and the sources block stays last. The panel still appears only when a figure for that college changed in
the past year.
