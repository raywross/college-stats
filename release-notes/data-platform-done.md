## What's new

The roadmap page no longer lists "the data platform" as work to do. Its four phases shipped between October 31 and
November 1, 2026: the pipelines write to the database, the site reads a published snapshot, every change carries
history and a revert, Quad's editors correct values in the console, and the code repository no longer holds the data.

## Behind the scenes

- The rollout spec is marked built and the roadmap entry removed, as built items are; the data platform overview
  stays among the roadmap's overviews with links to each part's "As built" section.
