## What's new
When a college announces its newest class, Quad can now carry what it said. A March release with how many applied
and were admitted, a September release with how many enrolled, a fact sheet or a newsletter: each becomes part of
that college's admissions page, with the college's own words and a link beside every number.

Under the funnel, a block called "Announced so far" lists what the college has said about the newest class that
isn't yet an exact count: "about 95,000 applied" when the college said "more than 95,000", a class goal, a deposits
count. The funnel itself, the hundred-square picture and the selectivity ranking keep using exact counts only, so a
rounded announcement never changes a college's tier.

Nothing comes from student newspapers or third-party sites. A publication the university runs counts; a number
for several campuses at once does not.

## Behind the scenes
Each announcement is a dated notice on the college's recipe, found three times a year for the most selective
colleges: an admits season in spring, a systems season in early summer, a census season in fall. Figures from every
notice that names the same entering term combine into one funnel, each with its own citation; the Common Data Set
replaces them when it arrives. A notice whose page names last year's class is never mistaken for this year's, and a
college whose news listing is known costs nothing to check again. The job's schedule follows the seasons; the first
census-season pass for this year's class runs once the owner starts it.
