## What's new

**Georgia Tech's fall 2025 admissions numbers are corrected.** Its profile now shows 66,912 applicants, 8,819
admitted (13.2%), and 4,050 first-year students, as printed in Georgia Tech's 2025 First-Year Profile. Before, it
showed 47,483 applicants and 4,434 admitted, which didn't come from that document.

## Behind the scenes

The earlier figures came from a run that read the class-profile PDF as a web page, before that was fixed. The record
was corrected by hand from the PDF, with each number quoted exactly as printed; the admit rate is computed from the two
counts and marked as derived.
