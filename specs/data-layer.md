## TypeScript Types

### Core Types (`lib/types.ts`)

```typescript
interface School {
  unit_id: string;
  name: string;
  location: {
    city: string;
    state: string;
    zip: string;
    region: string;
  };
  type: "public" | "private-nonprofit" | "private-forprofit";
  admissions: {
    year: number;
    applicants: number;
    admitted: number;
    enrolled: number;
    acceptance_rate: number;
    sat_reading_25_75: [number, number];
    sat_math_25_75: [number, number];
    act_composite_25_75: [number, number];
    test_submission_rate_sat: number;
    test_submission_rate_act: number;
  };
  demographics: {
    undergrad_enrollment: number;
    pell_grant_percent: number;
    first_gen_percent: number;
    racial_diversity: {
      asian: number;
      black: number;
      hispanic: number;
      white: number;
      two_or_more: number;
      international: number;
      other: number;
    };
  };
}

interface SearchFilters {
  q?: string;
  states?: string[];
  regions?: string[];
  minAR?: number;
  maxAR?: number;
  minSAT?: number;
  maxSAT?: number;
  minACT?: number;
  maxACT?: number;
  minEnroll?: number;
  maxEnroll?: number;
  types?: SchoolType[];
  sizes?: SizeBucket[]; // small | medium | large | xl
  sortBy?: SortKey;     // name | acceptance_rate | enrollment | sat | pell | first_gen | diversity

```

| Function | Signature | Description |
|---|---|---|

| `getSchoolById` | `(id: string) => School \| null` | Get single school |
| `getSchoolsByIds` | `(ids: string[]) => School[]` | Get multiple for comparison |
| `getStates` | `() => string[]` | Distinct states in data |

| `getDatasetSummary` | `()` | Totals for the home page |

## Derived metrics (`lib/metrics.ts`)
`satComposite`, `satMid`, `actMid`, `yieldRate`, `oneIn`, `diversityIndex` (Simpson's), `selectivityTier`,
`sizeBucket`. The `METRICS` registry maps each `MetricKey` to its getter, formatter, domain color, and glossary term.

Percentiles and medians are computed against the loaded dataset. When moving to Supabase, compute them in SQL
(or precompute) so they cover the full dataset.

## Dataset (`data/schools.json`)
~1,900 operating 4-year colleges, generated by `npm run sync-data`. See [data-sync.md](data-sync.md).
`lib/data.ts` reads it once per server process with `fs` (not a JSON import, which would make TypeScript infer
a huge literal type) and is marked `server-only`. The browser never receives the full list: client components call
`/api/schools` (`?q=` search, `?ids=` lookup) through `lib/school-api.ts`.

Performance: sorted value arrays are cached per metric, so `rankOf` is a binary search; similar-school vectors are
cached once per process.

### Adding newer primary-source figures
The sync covers every school. To layer in newer or verified figures (e.g. a Common Data Set published before IPEDS
catches up), add an entry to `data/overrides.json` (see [data-sync.md](data-sync.md)). Vanderbilt (`221999`) is the
example. Recipe for finding the numbers:
- **Admissions, test scores, enrollment, race/ethnicity**: the school's Common Data Set (sections C1, C9, B1, B2).
  Race shares use the "Total undergraduates" column; `other` = American Indian + Pacific Islander + unknown.
- **Pell and first-gen shares**: College Scorecard API (already synced; only override if needed) (`latest.aid.pell_grant_rate`,
  `latest.student.share_firstgeneration`); the CDS doesn't report them. `DEMO_KEY` works for one-off lookups.
- Cross-check: the Scorecard `admission_rate.overall` should equal CDS admitted ÷ applied.
- `unit_id` is the IPEDS ID; `region` follows the existing mapping (TN → Southeast).

## Future: Supabase Migration

When migrating, `lib/data.ts` functions will change from:
```typescript
// Local: read JSON file
import schools from "@/data/sample-schools.json";
export function getSchools(filters) { /* filter in memory */ }
```
to:
```typescript
// Supabase: query database
import { createClient } from "@supabase/supabase-js";
export async function getSchools(filters) { /* SQL query */ }
```

All function signatures become async, and page components add `await`.
