## What's new

**Graduation rates by group for 28 more colleges.** Colleges such as Iowa State, Elon, Colorado College, Harvey Mudd,
and Loyola Chicago now show how students with Pell grants, with federal loans, and with neither graduated, from the
college's own Common Data Set. These figures had been held back by a check that compared them with the wrong federal
class.

## Behind the scenes

Every saved Common Data Set was re-checked with the corrected graduation checks, with no new downloads or model calls:
2,140 graduation values that had been held now pass. A college's table publishes only when the whole table passes and
is newer than the federal figures, so 28 colleges change on the site. Four colleges' tables, including Central
Florida's and Springfield's, are newly held because their figures differ from the federal ones for the same class.
The re-check also exposed a gap: a total added up from parts with no line in the document could pass without a
citation. It now stays held, as it does on the first read, and a test covers it.
