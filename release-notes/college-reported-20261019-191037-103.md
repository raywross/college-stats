## What's new
- 187 college profiles show figures reported by the college itself (admit rates, class sizes, aid, outcomes) next to the federal figure, with the exact quote and link a popover away; 34 more have newer ones.
- Checkboxes in flattened PDFs are read right: the check and box glyphs some fonts leave behind count as marks, and a box whose mark never reached the text is left blank rather than held for a person to look at. 4,619 held values now pass and 2,743 unreadable checkboxes are blank instead of queued.
- Fourteen documents are filed under the edition their own text names (eight had been assumed a year too new or too old), and a duplicate copy of one college's 2024-25 set was dropped.

## Behind the scenes
- Run `20261019-191037-103`: 302 colleges attempted, 812 documents read, 100 colleges re-discovered, 348 escalated. Cost: $34.65.
- The circuit breaker tripped on check noise, not values: two aid-form rules fired whenever the form boxes went unread, and two thirds of the checkbox holds sat on lines with no mark of either kind. Both rules now need the boxes read as unchecked; an unreadable box is decided before any check runs so dependent checks see it as unread in the same pass.
- Merged by hand after a re-judge of every record (`npm run check-cds-records`); the review queue holds 20,086 items. What still trips the breaker is citation quality: the model cites the question line while the number sits on the next one (B22 retention, B1 rows), left for the Data Steward.
